# Unread

A make.fun entry for "One Word From Your Ex": exactly one word — the word
my ex would use to describe me.

`main.ts` (Node 22, standard library only) writes the word to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> Unread

Not someone who left — a message that was never opened. The notification
that sat there for three days, seen and unanswered.

Run it with `node main.ts`.
